# 协作区界面与旧记录清理

更新于 2026-09-08。本记录采用用户最新指示：删除“核对”按钮，并直接删除旧版任务转移记录；此前尝试回退旧转移、保留待核对提示的处理方式停止使用。

任务板标题前的收集箱图标已移除，关闭按钮移入任务板右上角，刷新位于其左侧。弹窗高度上限从 880 增至 960 像素，桌面视口上下预留合计 32 像素，手机预留合计 20 像素，腾出的区域用于内容。卡片不再显示任务说明，完整说明仍可通过详情入口查看或编辑。新的认领审批流程入口保留。

删除范围是协作存储中 `action=move` 的全部旧转移记录，包括已完成、未完成和已取消记录，以及 `legacyCleanup` 提示；解除这些记录在公共任务上的暂存标记。公共任务本身和滴答收集箱任务保留，新认领工作流程与正常的任务创建、编辑、完成操作记录保留。此次清理不调用滴答删除接口，也不依据同名任务推测删除对象。

清理通过现有服务器的串行写入过程执行，原子替换数据文件，重复触发不会重复变更。新版服务首次接到已登录成员的协作请求时执行，因此已在线页面的下一次任务板状态刷新也会触发；打开协作区的清理请求同样可用。候选部署容器只进行健康检查，不在启动时修改与旧服务共享的数据目录。

验证覆盖旧记录不同状态、已有“清理完成”标记但仍残留提示、未知任务编号，以及内容变化和来源缺失情形。测试确认旧历史被删除、真实任务数据及新流程保留；隔离的真实 HTTP 服务验证普通在线状态请求会触发迁移，未登录请求不触发。全项目 77 项测试通过，无跳过项。

当前未直接读取生产私有任务数据，不报告生产实际删除条数；代码发布后会按上述条件自动执行。浏览器实机布局尚未验收。
