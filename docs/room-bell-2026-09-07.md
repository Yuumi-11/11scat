# 单次摇铃与确认

实现：顶部铃铛入口，成员列表发送，接收方紧凑通知卡“知道了”，发起方取消，120 秒超时。服务器以身份校验权限，文件原子持久化、串行写入，活动会话合并、请求 ID 去重、30 秒发送冷却。沿用单容器部署，未来多副本需共享事务存储。

网页前台每 3 秒读取，后台 15 秒，返回前台/联网立即读取。确认、取消和超时以服务器状态为准，客户端不自动重发推送。同一身份多设备共用状态。

手机通知使用现有 VAPID 订阅，限定接收身份。推送 TTL 不超过会话剩余时间，独立通知 tag，不 renotify。Service Worker 校验活动会话，已取消/过期或无法核实时不弹出，避免旧提醒复活；网络异常时可能错过系统通知，仍可回站查看有效提醒。支持通知操作的平台可点“知道了”，其他平台点通知打开网站确认。结束后在线客户端清理本机通知；不承诺立即撤回离线手机/手表上的已送达通知，也不代表持续震动。

推送 accepted 只表示推送服务接受，不表示手机实际收到。页面显示等待确认，不伪称已送达；没有订阅/发送失败时明确显示。服务在写入成功但后台推送执行前崩溃可能漏推，不自动重发，避免多次震动。

设计参考：Carbon actionable notification https://carbondesignsystem.com/components/notification/usage/ 和 Slack 通知上下文 https://slack.com/help/articles/360025446073-Guide-to-Slack-notifications 。沿用本站主题色、Lucide 图标、紧凑圆角面板，没有全屏遮罩；支持小屏和减少动态效果。

验证：生产构建、TypeScript、17 项测试通过。新增实际隔离 HTTP 测试涵盖双身份发送/确认/读取、重复请求、跨来源阻止、他人权限拒绝；存储测试涵盖并发、过期、撤销；Service Worker 模拟测试涵盖去重、过期和确认。未向真实手机发送测试通知，Apple Watch 镜像震动及最终实机视觉仍需用户验收。
