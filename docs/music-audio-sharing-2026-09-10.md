# 桌面网易云声音分享

本轮按用户确认的方案实现：分享方使用桌面网易云正常播放，收听方通过自习室网站收听。不调用网易云一起听，不复制或修改任何人的网易云队列。

## 使用

分享方在音乐 → 更多下载 Windows 连接程序，运行后将本机配对码粘贴到网站。配对码不用发给对方。勾选允许对方请求收听，再发起或接受邀请。收听方接受邀请后点击“开始收听”。仅分享方需要连接程序。

收听方可调整自身音量，双方都能结束会话。关闭或收起音乐小窗继续收听；关闭网站、断开连接程序或结束会话会停止传输。若网络连接失败，结束后重新邀请。不会自动接受邀请或自动恢复已结束的分享。

## 实现

- `native/music-bridge/Bridge.cs`：Windows 进程 loopback，限定 `cloudmusic` 进程树，PCM 48 kHz、16-bit、双声道。没有麦克风采集、文件录音、客户端注入或账号读取路径。窗口关闭后进程退出，关闭本机 WebSocket 即结束采集。
- `127.0.0.1:19743` 只监听环回地址；随机 192-bit 配对码每次启动更换；校验 Origin 与 WebSocket 握手。不安装服务，不修改网易云。连接程序源码及构建脚本随项目保存；下载 ZIP 包含程序和说明，旁边提供 SHA-256 文件。程序尚未代码签名。
- 网站通过 AudioWorklet 将本机 PCM 接到独立 RTCPeerConnection，复用现有 `/api/realtime-config` 中的 TURN。VPS 实际未配置 LiveKit，因此最终实现不依赖 LiveKit，也未为音乐改变服务器配置。
- SDP 仅供本次邀请双方交换；接受前拒绝协商，发起方/接收方按领导者角色分别提交 offer/answer。声音通过 WebRTC 加密传送，服务器不录制，不缓存音频。中继会消耗现有 VPS 带宽。
- 分享意愿默认关闭。连接状态不等于授权上传；仅在邀请接受后添加发送轨道。私有状态不向第三人返回。
- “正在一起听”要求本端连接/接收成功且双方确认就绪；收听方以 RTC `totalSamplesReceived` 增长及实际播放状态确认。收到订阅/邀请本身不会生成成功状态。
- 邀请 120 秒过期；连接与会话使用心跳租期，服务重启会清除会话。信令错误会在本端关闭传输。后台、弱网与设备休眠可能结束会话，应重新邀请。

## 实测

- Windows 10.0.26200、网易云 3.1.23.204814，独立原生采集探测三秒取得 135360 帧、峰值约 0.7588；未保存音频。
- 浏览器真实配对通过；使用本机两个独立登录来源（127.0.0.1 与 localhost，测试昵称小蓝/小云）完成邀请、接受、收听、收起、结束及再次邀请。
- 强制使用现有生产 TURN 中继，收听端报告超过 1365600 个音频样本，双方显示“正在一起听”。这属于本机双端经过真实中继的测试，不能等同于对方实体电脑或手机验收。
- 暂不提供歌曲名、封面、精确播放进度、远程选歌或桌面队列同步。歌曲信息明确显示暂不可用。
- 还需要用户在对方实际设备上确认声音听感、长时间稳定性和浏览器本机连接许可。系统要求 Windows 构建号至少 20348；当前程序仅 Windows x64。
