## 2026-09-09：部署目标迁移

当日记录的 [Actions 运行 34251748455](https://github.com/yuumiqwq/duo-space/actions/runs/34251748455)完成了构建及镜像发布，但部署阶段仍从旧所有者的包位置拉取镜像。仓库地址与镜像地址是不同配置，修复需要同步服务器上已安装的部署脚本；源码推送成功本身不能证明服务器已经更新。

旧镜像地址 `ghcr.io/yuumi-11/11scat-web` 与新地址 `ghcr.io/yuumiqwq/11scat-web` 的差异保留在[部署说明](../../../deploy/README.md)中，旧镜像仍可能是回滚目标。归档描述的是当时故障，后续实际部署状态应读取目标提交的 Actions 结果，不沿用当日“尚待迁移”的状态。

当时保留了既有 GitHub Actions 与服务器交付方式，没有因为仓库还存在 Sites 配置而切换托管。原记录中的 108 项测试对应通知及恢复修改单元，未对真实滴答任务发送试验催办，也没有用模拟推送代替手机或手表送达验收。

工作流程与任务板曾从线上版本单独接入，教室外观仍留在本地分支；当时的 124 项检查只对应该次发布范围。后来教室及任务板外观获得上线许可，已发布的附件和审批修改再随教室版本合入，不能依据早期“仅本地”的记录推断后续仍未发布。
