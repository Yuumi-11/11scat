# 印章字体提前加载

进入房间时，已挂载的任务板组件立即请求 TaskStampLatin 与 TaskStampChinese，无需等用户打开任务板或出现第一枚印章。两套字体共用一次加载结果，反复打开任务板和组件重新挂载均复用已完成的加载。

字体未全部就绪时，印章保持透明并保留布局位置和认领者的无障碍说明，避免先显示默认字体再替换。加载失败不会被标记为就绪，重新打开任务板会重试。原始字体、署名和印章图案不变。

生产构建与 121 项自动检查通过，修改文件的 ESLint 检查通过。新增检查覆盖两套字体均就绪后再显示、并发复用、再次打开复用，以及下载失败和字体定义缺失后的重试。此次未完成浏览器实测，不将自动检查视为真实网络下的视觉验收。
