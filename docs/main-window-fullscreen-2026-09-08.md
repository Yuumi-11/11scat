# 主窗口全屏实施记录

日期：2026-09-08。对应新增 0 级需求：主窗口支持全屏，快捷键为 F，聊天框输入时不得触发。已完成代码实现，并从剩余需求中移除该项。

## 使用方式

主窗口指页面中展示共享屏幕、摄像头或画板的主显示区。共享画面与空白状态的右上角增加全屏图标，点击或按 F 进入浏览器原生全屏，再次点击、按 F 或按 Esc 退出；全屏时保留画面切换与现有画面操作。画板保留工具栏中的全屏按钮，并与主显示区共用状态，避免产生两层全屏。

聊天输入框、画板文本框以及其他输入控件获得焦点时，F 保持正常输入。判断同时检查焦点元素、事件目标和事件传播路径，兼容可编辑区域内的子节点；中文输入法组合输入、Ctrl/Alt/Meta 组合键、长按产生的重复事件以及已被其他控件处理的事件均不触发全屏。Shift+F 和普通 F 都可用于切换。

全屏状态根据浏览器的 `fullscreenchange` 事件更新，因此通过 Esc 或浏览器自身操作退出后，按钮也会恢复。连续操作等待当前请求完成，浏览器不支持或拒绝请求时显示提示，不提前显示进入成功；若其他查看器已经占用全屏，F 不接管该查看器。

## 实现与验证

`app/use-main-fullscreen.ts` 管理主显示区引用、全屏事件和操作中的状态，`app/fullscreen-controls.ts` 负责输入保护及原生 API 调用。`app/main-fullscreen.css` 定义随主题变化的按钮和全屏尺寸，`app/Whiteboard.tsx` 使用主显示区提供的全屏状态与回调。

生产构建通过，全部 22 项测试通过。新增测试覆盖输入焦点、传播路径及输入法保护，同时验证原生全屏进入和退出、其他查看器占用以及请求失败；这些测试使用模拟 DOM 与 API，并未操作真实浏览器。修改文件 ESLint 无错误，保留页面已有的 4 条图片优化提示。

浏览器工具此前的恢复操作被自动审批检查拒绝，本次没有重试该操作，未完成真实浏览器全屏及移动设备验收。实现使用标准 Fullscreen API，不支持该 API 的浏览器会显示失败提示；不以页面放大替代原生全屏。
