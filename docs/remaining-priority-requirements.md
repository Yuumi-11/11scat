# 剩余需求执行表

更新时间：2026-09-07

本文档仅保留已经设置紧急等级、且未在本轮筛选中标记为删除的需求。复选框用于后续依次实施和验收。

## 【0】最高紧急等级

### 1. 修复消息无法及时送达或完全不可见

- [ ] 排查已发送消息对方看不到或经过较长时间才显示的问题。
- [ ] 检查消息写入服务器、实时推送、客户端确认和断线重连后的补发流程。
- [ ] 实时推送遗漏时，客户端能够重新同步缺失消息，并通过唯一消息标识避免重复显示。

**验收条件：** 至少使用两台设备持续互发消息，并覆盖多人同时发送、短暂断网后恢复及聊天室与任务板切换场景；消息不得丢失、异常延迟或重复出现。

### 2. 发送上一条消息期间保留新输入内容

- [ ] 用户按 Enter 后，将本次消息保存为独立的待发送副本，输入框立即进入新的草稿状态。
- [ ] 上一条消息发送成功、失败或超时，均不得清空、覆盖或回退此后输入的新文字。
- [ ] 发送失败时，在对应消息上显示失败与重试状态，不把旧内容放回输入框覆盖新草稿。

**验收条件：** 在网络延迟环境下，发送上一条消息后立即输入下一条内容，新输入文字始终完整保留。

### 3. 修复多人画板吞笔和笔画闪现

- [ ] 多位用户同时绘制时，每一笔都及时、持续地显示在所有参与者界面中。
- [ ] 检查绘制事件的唯一标识、到达顺序及客户端状态合并方式，避免旧画板状态覆盖新笔画。
- [ ] 并发使用画笔、两种橡皮模式和清屏操作时，各设备最终画面保持一致。

**验收条件：** 至少两台设备持续同时绘制，过程中不再出现笔画被吞、消失后重新出现或各端画面不一致。

### 4. 修复画板保存后的文本框位置和大小

- [ ] 保存结果保持文本框坐标、宽高和文字缩放比例与保存前画板一致。
- [ ] 全屏、窗口模式及不同浏览器缩放比例下，文本不得发生位置或尺寸变化。

**验收条件：** 将同一画板在不同显示模式下保存到云盘，保存图片中的文本布局与保存前画面一致。

### 5. 聊天图片改为弹窗查看

- [ ] 取消点击聊天图片后打开独立网页的现有行为，在当前聊天页面内显示图片弹窗。
- [ ] 弹窗右上角提供清晰可见的 `×` 按钮，点击后关闭弹窗。
- [ ] 弹窗显示时，图片以外的页面区域呈半透明效果。
- [ ] 关闭弹窗后保留图片打开前的聊天滚动位置，不刷新记录或跳到其他消息。

**验收条件：** 图片在当前聊天页面内放大显示，右上角可以关闭，周围区域呈半透明效果；关闭后仍停留在原来的聊天阅读位置。

### 6. 画板文本框使用滚轮调整文字大小

- [ ] 文本框处于虚线框编辑状态且鼠标位于框内时，滚轮向上放大文字、向下缩小文字。
- [ ] 调整结果即时显示，按 Enter 后随文本框保存。
- [ ] 其他状态下保留画板或页面原有滚轮行为，调整字体时不得改变文本框位置和尺寸。

**验收条件：** 编辑态可以通过滚轮连续调整字号，确定后显示和保存结果一致。

### 7. 通过任务板向其他成员添加滴答待办

- [ ] 查看其他成员区块时，在其“XX正在”状态行右上方显示 `+` 按钮。
- [ ] 点击后弹出轻量输入气泡，填写内容并按 Enter，待办直接添加到对应成员的滴答清单。
- [ ] 新建待办默认不设置日期；开发前确认滴答清单接口是否支持无日期任务。
- [ ] 用户自己的任务区块不显示 `+` 按钮。

**验收条件：** 向指定成员提交待办后，该任务进入正确成员的滴答清单，不会写入发起人的清单。

### 8. 限定跨用户任务权限

- [ ] 跨用户操作仅允许新建待办。
- [ ] 用户不能勾选、完成、取消完成或修改其他成员已有的任务。

**验收条件：** 他人任务卡片中的完成与修改操作始终不可用，同时新增待办功能正常工作。

### 9. 显示他人添加的新待办提醒

- [ ] 当其他成员为当前用户添加待办后，在本人区块原 `+` 按钮对应位置显示“新”按钮。
- [ ] 点击后弹窗列出自上次打开以来由其他成员添加的全部新待办。
- [ ] 关闭弹窗后将所列内容标记为已查看并隐藏“新”按钮，之后收到新待办时再次显示。

**验收条件：** 新增记录按用户分别维护，查看后提醒消失，下一次新增时能够重新出现。

## 【1】较高紧急等级

### 10. 替换简陋图标并统一美术资源

- [ ] 通过网络搜索成熟方案，选择授权允许且风格统一的图标资源或图标库。
- [ ] 替换现有简陋线条图标和以汉字充当图标的功能入口。
- [ ] 统一图标尺寸、线条粗细和交互状态，并配合人工编写的简短悬停提示。

**验收条件：** 常用功能使用容易识别的图形图标，不再以单个汉字代替图标，各区域图标风格一致。

### 11. 云盘图片使用缩略图展示

- [ ] 云盘中的图片文件以缩略图形式显示，并保留文件名等必要信息。
- [ ] 点击缩略图后可以查看清晰原图。

**验收条件：** 用户无需逐个打开文件即可通过缩略图辨认图片内容，原图查看功能正常。

### 12. 增加持续摇铃功能

- [ ] 增加摇铃按钮，点击后其他房间成员的手机和手表显示类似来电的持续提醒并保持震动。
- [ ] 发起人的按钮显示正在摇铃状态，再次点击同一按钮后结束提醒并使所有接收设备停止震动。
- [ ] 调查手机浏览器、PWA、系统通知和不同品牌手表的支持范围，并说明所需权限或配套程序。

**验收条件：** 摇铃与普通消息的一次性震动能够明确区分，同一次摇铃不会产生多个重复的持续提醒。

### 13. 聊天室发送和保存语音消息

- [ ] 聊天输入区域支持录制并发送语音，语音消息可以播放、暂停和查看进度。
- [ ] 语音随聊天记录长期保存，重新进入房间或加载历史消息后仍可播放。
- [ ] 语音不自动进入云盘，用户主动点击保存后写入 `/video` 文件夹；文件夹不存在时自动创建。

**验收条件：** 语音可以完成录制、发送、历史回放和手动保存，并继续遵循云盘容量限制与提示规则。

### 14. 调查并选择性实现语音转文字

- [ ] 调查语音识别方案、模型调用方式、实际费用、中文识别效果和服务器处理负担。
- [ ] 成本与效果可接受时一并实现，当前条件不适合时允许暂不增加转文字。

**验收条件：** 先形成可行性说明；未验证方案前，不阻碍语音录制、发送、播放和保存功能交付。

## 【2】普通紧急等级

### 15. 研究网易云音乐播放状态同步

- [ ] 调查能否同步歌曲名称、歌手、播放或暂停状态及当前播放进度。
- [ ] 分别确认网易云音乐网页版和桌面客户端能够支持到什么程度。
- [ ] 优先调查合法且可靠的官方接口；若需本机程序、浏览器扩展或非官方接口，说明安装成本、登录依赖、稳定性和账号风险。

**验收条件：** 先提交可行性说明和推荐方案，确认技术路径后再决定是否开发。

### 16. 简化聊天附件的云盘保存按钮

- [ ] 将聊天图片和语音旁完整文字形式的“上传到云盘”按钮改为单个简洁图标。
- [ ] 图标配合人工编写的“保存到云盘”悬停提示，并显示上传中、成功或失败状态。
- [ ] 成功后可以短暂变色或显示完成标记，不恢复为占用较多空间的文字按钮。

**验收条件：** 图片和语音使用一致的云盘保存图标，状态反馈完整且界面占用明显减少。

## 【3】较低紧急等级

### 17. 重新设计全站 UI 视觉风格

- [ ] 通过网络搜索和学习美观、成熟的 UI 风格，为全站形成新的视觉方案。
- [ ] 参考范围不限于学习网站，可以借鉴任何适合本项目且视觉效果优秀的界面。
- [ ] 设计目标为更加高级、清新、好看，并保持各页面和组件的视觉风格协调统一。

**验收条件：** 改版后的配色、字体、图标和组件样式形成统一且清新的视觉语言，不再呈现简陋或临时拼接的效果。
