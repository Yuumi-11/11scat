# 审批规则调整与独立音乐模块移除

按用户 2026-09-10 的最新要求，审批是否通过由审批人决定。任务提交后发生变化不再触发强制打回，网站详情修改也保持待审批；如需补充成果，由审批人先打回，认领者再提交。原有成果说明和附件继续保留。

服务端已取消通过前及完成同步中的提交版本比较，完成时使用当前关联任务并保存完成记录。权限校验和过期流程请求检查继续生效；重复任务的完成响应不明确时，仍避免再次勾选下一次任务。针对内容修改与仅 etag 变化补充了验证，覆盖双方任务、公共任务和中断重试。

独立音乐功能与已有投屏电脑音频功能重复，按用户要求整体移除。删除首页入口与两套音乐界面，移除音乐专用接口和预览页；Windows 连接程序源码、构建脚本及下载包也一并删除。音乐专属测试与说明文档移除，剩余需求表取消网易云状态同步待办。Git 历史及以前综合调研记录仅作为历史资料，不表示仍需开发。

现有投屏的电脑音频选择、音轨传输和播放继续使用原有实现，通用语音消息、麦克风与实时通信配置不属于本次删除范围。

验证：生产构建与类型检查通过，修改文件的 ESLint 无错误。全套测试首次通过 127 项；为本次检查准备临时 FFmpeg/FFprobe 后，剩余两项真实音频转换与 HTTP 播放测试也通过，共验证 129 项。实际 Next HTTP 测试确认提交后修改仍可审批，且原提交附件可读取；另用隔离服务确认两套旧音乐接口的 GET/POST、预览页和下载资源均返回 404，首页正常返回且无音乐入口。真实用户任务与音频会话未被用于测试。
