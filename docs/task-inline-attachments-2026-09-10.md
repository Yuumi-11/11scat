# 说明正文中的附件文件名

粘贴文件时，说明编辑器保留光标范围，在上传成功后将可点击的文件名插入原位置；存在文字选区时替换选中部分。多文件按粘贴顺序插入，失败文件不占位置，全部失败时保留选中文字。上传期间暂停编辑，结束后恢复光标到插入内容之后。

图片和其他附件统一显示完整文件名，包含扩展名，不展示缩略图，也不重复附加类型名称。底部附件卡片保留。图片文件名点击后打开原有预览弹窗，其他文件打开附件页面。普通文本粘贴使用纯文本方式，保留换行，不引入外部富文本样式。

存储仍采用说明中的附件链接，滴答同步协议和云盘位置不变。网站编辑和阅读时将链接显示为文件名，已有附件链接也会按正文位置显示。

构建、静态检查与 130 项自动检查通过，另行验证详情渲染保留附件前后文字及底部卡片。本轮未完成真实浏览器剪贴板、输入法和光标交互的人工验收。
