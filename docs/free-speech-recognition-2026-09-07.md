# 免费语音转文字方案补充调研

调研日期：2026-09-07。对应原需求第 14 项新增批注“语音转文字有免费方案吗”，本报告补充开源自托管与浏览器本机处理方案，不改变已经交付的录音、发送和历史播放功能。

## 能否免费使用

可以使用无需按分钟付费的开源模型。Whisper 的代码和模型权重采用 MIT 许可，可以在自己的设备或服务器运行；使用者仍需承担模型下载、计算资源和维护成本，因此“免识别接口费”不等于整个运行过程没有成本。[F1]

对于本项目，建议优先试用 `faster-whisper` 的多语言 `small` 模型与 CPU INT8 推理；如果主要考虑中文和粤语，可将 SenseVoiceSmall 纳入同一批录音对照。当前尚未核实生产服务器的可用内存、CPU 余量和中文样本效果，本轮不直接给正式服务器增加模型进程，以免影响聊天及协作功能。

## 候选方案比较

| 方案 | 接口费用与许可 | 资源及接入方式 | 对本项目的适用判断 |
| --- | --- | --- | --- |
| Whisper + faster-whisper | 自托管无按分钟接口费；Whisper 代码及权重、faster-whisper 实现均为 MIT | 独立 Python 识别服务，CPU 可使用 INT8；模型首次运行需要下载并缓存 | 推荐作为第一组基准，使用多语言模型，不能误选仅英语的 `.en` 模型 |
| SenseVoiceSmall | 代码为 MIT；官方权重需单独遵守模型卡所列 FunASR Model Open Source License Agreement | 官方仓库提供 Python、CPU 和容器化运行路径；还需语音活动检测及文本后处理 | 中文、粤语候选，维护者展示的优势仍需用本项目录音验证，不能从代码 MIT 许可直接推导所有转换权重许可相同 |
| whisper.cpp 本机或 WebAssembly | 实现采用 MIT；Whisper 模型来源与许可见 F1 | 可运行 CPU 原生程序，也有 WebAssembly 示例；浏览器方案将计算与下载放在用户设备 | 适合希望音频尽量留在本机的使用方式；手机内存、耗电和首次下载体验需要单独评估 |

faster-whisper 官方 README 的现有基准以 **13 分钟音频、Intel Core i7-12700K、8 个线程**为条件，列出 `small` 模型 INT8 推理约 1 分 42 秒、内存约 1,477 MB；该页面标明基准版本为 v1.1.0。它是作者在指定机器上的参考数据，不是本项目 VPS 或中文录音的实测结果，不能据此承诺本站 1 秒语音能在固定时间内完成识别。[F2]

whisper.cpp 当前 README 列出的未量化模型资源参考如下。量化可以进一步减少磁盘和内存开销，但不同格式、后端及音频长度会影响实际峰值，表中数据不能替代部署测量。[F3]

| 多语言模型 | 模型文件 | 运行内存参考 |
| --- | --- | --- |
| `tiny` | 75 MiB | 约 273 MB |
| `base` | 142 MiB | 约 388 MB |
| `small` | 466 MiB | 约 852 MB |

SenseVoice 官方仓库说明 Small 版本覆盖中文、粤语、英语、日语和韩语，并给出中文及粤语评估结果；这些属于模型作者报告。仓库同时明确区分源代码许可与模型权重许可，并提示第三方转换格式可能使用不同条款，因此实际下载哪个模型文件，应按该文件对应的模型卡保留声明。[F4]

## 推荐实施方式与本轮决定

后续采用“手动点击转文字 → 后台队列 → 保存结果”的流程，原语音始终保留。识别服务单独运行，首轮并发限制为 1，先用 20 至 30 段已获允许的普通话、口音及术语混合样本比较 `small` INT8 与 SenseVoiceSmall，记录文字错误、处理时间及峰值内存，再决定正式采用哪一个。模型结果按附件和模型版本缓存，同一录音不重复消耗算力。

浏览器自带语音识别不能直接视作本需求的免费通用替代品：需要验证它能否处理已经保存的音频文件，并确认具体浏览器是否依赖厂商在线服务。各种商业识别平台的限时赠送额度也不属于可长期保证的免费方案，本轮不据此开通付费账户。

**处理结果：已完成免费方案补充调研，语音转文字暂未实现。** 有可用的免接口费路线，但正式部署资源和代表性中文样本尚未验证；这符合第 14 项允许在当前条件不适合时暂不增加转文字的要求。本轮没有下载大型模型，没有上传私人音频，也没有产生识别费用。
