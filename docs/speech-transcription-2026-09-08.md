# 语音转文字实施记录

更新于 2026-09-08。已按用户选择接入 Cloudflare Workers AI Whisper Large V3 Turbo，采用现有服务器调用 REST API 的方式，无须另建 Worker。代码和页面入口已完成，实际服务授权尚未配置；当前不能宣称已成功转写真实录音。

## 使用方式

每条聊天语音下方增加“转文字”，点按后将这条音频提交给 Cloudflare。录音、发送和播放都不会自动触发识别；完成后文字显示在播放器下方，可收起并再次展开。转写结果保存在本站数据目录，同室其他成员点按查看时共用缓存，刷新或重启不会丢失。没有识别到说话内容时显示相应提示。

历史语音也可以转写。服务复用播放兼容版本，输入为 AAC/M4A，按官方模型输入结构编码成 Base64；启用语音活动检测，保留原语种。识别文字按普通文本呈现，不执行其中的 HTML。

## 免费额度与资源限制

官方 Free 计划每日提供 10,000 Neurons，UTC 00:00，也就是北京时间 08:00 重置。Whisper Turbo 每音频分钟消耗 46.63 Neurons，全部用于该模型时理论约 214 分钟；与账户其他模型共用额度。

本站设置每日 180 分钟的保守上限，并对每条音频向上取整秒数后再预留 1 秒。上限按全部成员合计，不会由每个页面分别计算。发送请求前持久化使用量，失败或结果不明的请求也保留占用；服务中断后不立即自动重发。超过本站上限后拒绝新转写，服务端返回额度或请求限制时暂停至下次重置，已有文字仍可查看。

服务器串行转写，最多接收 6 条不同音频的进行中或排队请求；同条音频并发点按共用一次处理。单条最长 305 秒，兼容版本最多 4 MiB，远端请求最多等待 60 秒。网络中断只影响此次转写，语音仍可播放；用户稍后点按重试，不设置后台识别轮询。

这些限制不能代替 Cloudflare 账户的计费计划。部署者必须确认账户为 Workers AI Free 计划，账户若被升级为 Paid，本站无法替其他应用限制该账户的费用。本实现不会升级计划，也没有付费服务回退。

## 部署者需要完成的一次配置

1. 在 Cloudflare 账户确认 Workers AI 使用 Free 计划，复制账户 ID。创建专用 API Token，使用 Workers AI 模板，只授权该账户的 Workers AI Read 和 Workers AI Edit。
2. 在服务器 `/opt/11scat-web/identity.env` 设置 `CLOUDFLARE_ACCOUNT_ID` 和 `CLOUDFLARE_WORKERS_AI_TOKEN`，确认免费计划后将 `CLOUDFLARE_AI_FREE_PLAN_CONFIRMED` 设为 `true`。变量模板已加入 `deploy/identity.env.example`，真实令牌只存于服务器，不放进 Git 或网页。
3. 通过项目既有部署流程重建容器，使其重新读取环境文件。然后在聊天里选一条短中文语音点按“转文字”，确认首次结果与再次查看缓存，再验证手机上的显示和中文识别效果。

本轮没有发现可用 Cloudflare 授权，没有读取生产环境密钥。缺少配置时入口显示“语音转文字尚未连接”，原有播放和发送继续可用。上述账号配置是启用真实转写的剩余步骤。
