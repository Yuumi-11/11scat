# 教室主题本地实现

日期：2026-09-09。**仅限本地调试。用户明确要求所有外观制作先不推送、不上线，必须等用户再次明确允许。** 本地改动保存在 codex/classroom-local 分支，不向该分支设置远端跟踪，也不部署已有 Sites 或服务器环境。

## 本地查看

开发服务启动后访问 http://127.0.0.1:3008/classroom-preview 。这是一份使用示例数据的本地交互预览，复用正式素材、字体和 Whiteboard 组件，可以切换待机、投影、画板及同桌，试写笔迹并重新载入。画板保存入口在此预览中下载本地 PNG，不上传云盘。

390、768 和 1440 像素的布局检查入口分别为 /classroom-preview?width=390、?width=768、?width=1440。预览路由只在开发环境启用，生产环境返回 404；它不读取真实成员数据，也不生成真实任务、消息或摇铃通知。正式首页继续经过原登录校验。

## 当前实现

黑板与传纸条区域去掉顶栏后上移，四张课桌只占底部少量高度，人物和投影缩略图均已移除。前两桌的台历显示用户 ID 与活动，自己的活动支持最多 80 字和 Enter 保存，保留输入法组合保护及原身份同步流程。投屏中的用户台历高亮，点击对应名称可切换媒体。

画板、摄像头等控制移到第三桌，任务板、云盘和设置移到第四桌；任务夹板有支架，摇铃使用实体铃铛。设置保留消息提醒子菜单，固定教室主题不再受先前保存的自由颜色和背景图片影响；没有新增性别字段或聊天已读回执。麦克风沿用原有入口，其原先未接入的独立语音通话功能不属于本轮新增内容。

待机黑板试用辰宇落雁体与颗粒遮罩显示公共任务，缺字由龙藏体补齐。2026-09-10 起改为从上方排列，依据文字实际换行高度计算显示数量，不再固定三条。公共任务来自现有的轻量刷新响应，读取本地公共任务数据，不增加定时器或滴答请求。英文日期使用 CHAWP，日期边界统一使用北京时间，午夜和重新显示页面时更新。

投影布从画面顶端展开，盖住待机文字，投影仪始终位于幕布前方并支持点击收起。投影展开期间原有媒体切换和声音控制保留，结束共享另有桌面入口；打开画板时隐藏待机任务与日期。聊天消息改成轻微不规则的平面纸条，取消折角和输入占位文字。

同桌面板左右均分，只显示双方今天的未完成任务。日期处理保留全天任务的日期标签，并将带时区的截止时间转换到北京时间；逾期、未来及无日期任务不进入该视图。原接口的其他日期模式与任务勾选权限保持原行为。

## 粉笔绘制与兼容

正式画板使用固定种子的轮廓变化与颗粒，复用同一个绘制器显示、重新载入和导出。常规移动只重新绘制正在变化的笔画，已确定的前序笔迹使用缓存；删除笔画或收到更新版本时重建对应画面。

白色粉笔与局部板擦有明确的工具字段，重连、消息分包及合并后仍能区分。旧画板中的白色擦除笔迹按原语义处理，旧的默认深色笔迹以浅色显示在新黑板上，保留已有内容的可见性。文本继续可编辑、移动和删除，新文字使用辰宇落雁体及龙藏体缺字回退；固定颜色入口移到右下角实物粉笔，自定义颜色仍可使用。

## 验证结果与边界

- 生产构建和 TypeScript 检查通过，修改范围内的静态规则检查通过。构建仍提示原有文件读取路径导致跟踪范围过宽，这属于既有配置问题，本轮没有修改该配置。
- 120 项自动检查通过，覆盖活动保存、协作权限和消息等已有行为。新增检查涵盖今天日期边界、公共任务显示顺序、粉笔与板擦格式，以及分包和重连后的保留情况。
- 实际像素检查覆盖白色粉笔可见性、颗粒透明度、重新绘制一致性与局部擦除；笔迹更新、删除和清屏后重新绘制也通过。同一绘制引擎中相同数据一致，不承诺不同系统的字体栅格化逐像素相同。
- 浏览器已查看桌面待机、展开投影及真实自由书写，确认能够连续记录多个采样点。已检查手机宽度主要布局，并修正日期与投影仪的重叠位置；仍待平板及真机完整复核。
- 平板截图操作被自动审批审查拒绝，系统未给出具体原因。已停止此项浏览器操作，没有改用其他控制方式绕过限制，因此没有把平板检查标为完成。

真实账号的双人投屏、摄像头和移动端触控仍需在本地验收；本轮未操作线上账号数据，也未发布外观改动。用户已取消新一轮整页生成效果图，后续以实际网页为评审对象。

源图与可复用的生成提示词见[素材清单](classroom-asset-prompts-2026-09-09.md)，固定视觉要求见[教室设计说明](classroom-flat-style-2026-09-09.md)。

本轮使用已核实授权的 Black Paper 细颗粒与 ambientCG Paper001 纸纤维替换对应纹理，画板导出同步采用新黑板表面。具体取值、候选比较及验证结果见[材质与布局调整说明](classroom-material-refinement-2026-09-09.md)，所有外观改动继续只供本地查看。

第二轮批注已继续接入：粉笔改放右下角并靠木边，黑板试用辰宇落雁体，第三桌按第四桌风格重画并统一等比显示。投影仪改为背面朝向，始终位于幕布前方，并支持点击收起与展开；布局顶部和栏间空隙进一步减少，聊天消息间距缩小。第四桌源素材未改动，当前效果与验证详情见[第二轮说明](classroom-second-review-2026-09-09.md)。
