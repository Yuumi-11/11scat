# 教室主题第六轮本地调整

本轮对应八条截图批注及新增的相机红灯要求。修改继续保存在 `codex/classroom-local`，不推送、不部署，开发预览服务保持运行；上一轮之外的粉笔装饰素材没有改动。

## 当前实现

| 批注 | 修改 |
| --- | --- |
| 1 | 平板和笔记本的最大宽度由 280px 调整为 240px，保留 3:2 素材画布比例，顶部约下移 27px，接近此前台历的上沿。平板改为浅粉保护套，右侧露出折叠支撑，亮暗屏使用相同轮廓。 |
| 2 | 画板右上角加入颗粒粉笔风格关闭图案；点击返回默认黑板，不删除画板内容，仍可从侧面切回。 |
| 3、补充 | 投影仪与相机红灯增加小范围径向光晕和暖白亮点，不对整件物品应用发光。相机只随本机摄像头开启状态亮灯；投影仪随房间是否存在视频来源显示工作状态。 |
| 4 | 默认黑板和画板共用前板及托槽的坐标，装饰粉笔使用与交互粉笔相同的槽位尺寸。自定义彩色粉笔在默认黑板中保留空位，板擦不再向右补位。 |
| 5 | 改为可见的后板、前板和上下滑轨，前板两侧露出绿色后板；侧面采用小把手和嵌入箭头，整条侧面仍可点击。保留原黑板颗粒与外木框，绘画区域位于前板内。 |
| 6 | 移除被现有裁切影响的外置木纹伪元素，在聊天框真实边框区域直接铺设黑板同一木纹。纸张层仅铺到内边界，保留圆角及现有纸面。 |
| 7 | 活动内容增加顶部留白与两侧 3px 间距，使用浅色圆角活动区域；输入高度由缩小后的可用屏幕空间决定，继续多行输入和容量限制。 |
| 8 | 用户名与媒体操作分别由 `DeviceIdentity`、`DeviceMediaControls` 渲染，用户名独立放在左上，字号提高到 18px，较窄设备为 15px。设备屏幕使用简单浅色活动区和底部短横条，默认字体改为幼圆，未安装时回退 Noto Sans SC。 |

平板离开差分已在上一轮实现，本轮同步更新为粉色保护套。预览底部新增“本人离开”，可以直接查看第一桌暗屏；点击“同桌离开”查看另一位成员的暗屏。真实页面仍由成员在线状态决定，不依赖演示按钮。

## 响应式取值

设备仍采用等比缩放，并以 240px 为最大宽度。屏幕内小于等于 210px 的设备使用容器条件调整字号和留白，适配每张桌子的真实可用空间，避免只根据浏览器总宽度估算。活动区以顶部 16px、两侧 3px 和屏幕底部 8px 为桌面参照；笔记本因可用屏幕高度较少，顶部留白为 12px。批注中 175×93px 的文本框不固定套用，因为设备整体缩小后不能同时保留旧高度。

后板在桌面两侧各露出 26px，手机各露出 18px；点击区域与露出区域一致。前板内容、粉笔槽位和关闭按钮都在主窗口内容中，仍使用上一轮的统一全屏缩放。
