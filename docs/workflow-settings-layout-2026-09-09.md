# 工作流程详细设置布局

按用户截图调整：仅保留保存修改按钮，关闭详情放弃未保存的草稿。优先级提供低、中、高三个互斥按钮，再次点击当前选项清除优先级。重复与提醒使用相邻的单选按钮，并移至日期行下方、标签上方；既有自定义规则仍可保留。

开始时间、结束时间与全天开关同排。日期通过按钮调用系统日历选择器，已选值作为只读文字展示，可单独清除；取消全天后仍可在系统选择器中选择时间。

详情弹窗使用视口高度约束，左侧任务内容与记录独立滚动，右侧设置不使用页面滚动。说明输入框填充其余高度，短窗口缩小控件间距。窄屏上下排列，记录区保留独立滚动，设置区获得主要高度。

生产构建和 121 项自动检查通过。浏览器准备操作被自动审批检查拒绝，本轮未完成视觉或系统日历交互实测，不能据此保证所有屏幕尺寸的视觉验收结果。
