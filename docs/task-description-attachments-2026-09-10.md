# 任务说明中的粘贴附件

任务编辑和工作流程详细设置的说明输入框支持粘贴截图、图片，以及浏览器剪贴板提供的文件对象；纯文字粘贴保持原行为。文件先存入云盘 `tasks/任务编号/独立编号/文件名`，每个文件使用独立目录，避免同名覆盖。单文件限制为 20 MiB，服务端流式检查大小，并沿用云盘容量限制和登录权限。

上传成功后，说明草稿中追加文件链接并显示附件入口。点击保存修改后，链接随原有任务说明同步流程进入滴答；未认领的公共任务先保存在网站，认领时随说明进入接收者任务。上传期间不能提交设置，上传开始时固定草稿版本以保留并发修改保护。多文件逐个处理，部分失败不会丢弃成功文件。

任务板、任务编辑与工作流程详情均展示附件入口。图片使用现有图片弹窗，PDF 在新页面打开，其他格式按浏览器支持预览或下载。滴答中的链接先经过网站登录入口，再访问云盘文件。文件没有向滴答作为原生附件上传，不占用滴答附件上传额度。

上传与保存任务是两个步骤。关闭未保存的草稿不删除已上传的云盘文件；文件仍可在云盘 tasks 中找到。用户在云盘手动移动、重命名或删除文件，会影响既有链接。浏览器未向网页提供的剪贴板文件类型无法通过粘贴读取。

验证：构建和 129 项检查通过。新增 HTTP 验证覆盖云盘上传、其他房间成员读取、登录返回链接、路径检查、跨站写入拒绝及附件大小限制；链接解析覆盖中文、括号文件名与普通文本。修改文件静态检查通过。未操作真实滴答任务，未完成浏览器系统剪贴板的人工视觉验收。
