# 任务说明中的粘贴附件

更新于 2026-09-11，按用户两张截图的批注调整。任务编辑和工作流程详细设置的说明输入框支持粘贴截图、图片，以及浏览器剪贴板提供的文件对象，纯文字粘贴保持原行为。附件仍在光标处显示为“文件名.扩展名”，单文件限制为 20 MiB。

## 保存时同步云盘

粘贴文件只上传到独立暂存区，未保存时不会进入云盘，暂存文件仅当前上传成员可读取。点击保存修改后，服务端先检查任务版本与字段，再准备本次引用的附件，按原有流程同步任务内容。未保存就关闭窗口或在保存前移除的附件不会成为云盘文件；超过 24 小时的暂存数据在后续上传时清理，过期草稿需要重新添加附件。

附件最终保存在 `tasks/任务编号/独立编号/文件名`，同名文件使用不同路径，写入云盘后清理暂存副本并释放暂存额度。上传期间不能提交设置，保存失败保留可重试的任务记录。链接随任务说明同步滴答，不使用滴答原生附件上传接口。

从说明中移除附件后，只有保存修改才会删除对应云盘文件。服务端使用已保存的旧说明与新说明比较，不接受客户端单独指定任意文件删除；任务内容同步确认后再清理文件，清理失败保留待处理记录，服务重启后可继续。之前上传的附件也适用此规则，但不会清理与此次修改无关的历史文件。其他当前任务仍引用同一文件时保留文件，最后一个引用移除后再删除；历史变动记录只保留文件名说明。

## 预览与记录

任务说明内和附件列表中的入口均在当前页面打开预览弹窗，右上方提供下载与关闭选项。图片与常见文字文件可直接查看，PDF 使用浏览器内嵌查看器，音视频提供播放控件；其他格式显示下载入口。文本按纯文字呈现，最多预览前 1 MiB，关闭弹窗后返回原任务编辑位置。滴答中的外部链接继续经过网站登录后访问文件。

删除原来的“附件已保存云盘，保存修改后同步任务链接”提示。流程记录中的附件变动显示文件名和扩展名，例如“说明：image.png → input.txt”；旧记录在显示时采用同样的转换，不再展露原始附件链接。
