# 免费手写字体与自由粉笔笔画验证

日期：2026-09-09。用户认为前轮字体的手写特征偏弱，要求寻找免费手写字体，再添加颗粒模拟粉笔。本轮比较新的实际字形，并制作能真正自由书写的独立原型；颜色与整体材质仍以[用户固定参照](assets/classroom-approved-material-reference-2026-09-09.png)为准，本原型只用于验证笔迹，不是新版整页效果图。

## 字体实样与建议

本轮优先建议比较龙藏体，其字形带有自然的手写斜度和笔画变化，同时较容易辨认；志莽行书的行书笔势更明显，适合进一步对比。二者都通过了本次 6763 个 GB2312 汉字的覆盖检查，授权来源为 Google Fonts 收录的 OFL 1.1 字体文件及说明。

每种字体上行是原始字形，下行添加固定颗粒显示层，均直接使用下载字体的真实轮廓。橙色方框表示该字体缺少字符，没有让系统后备字体代填。颗粒强度只是样例参数，可以调整；无需修改用户任务文本或把简体转换成繁体。

## 自由笔画能否接近效果图

可以把自由线条做成有颗粒、轻微缺损和边缘起伏的粉笔笔迹。示意图中的曲线形状属于绘画内容，程序负责笔触质感，不能在不改变用户意图的情况下自动得到相同构图或字形。字体用于自动显示的公共任务，自由书写使用用户输入的点列，二者可以共享颗粒风格，但不共用字形来源。

[打开粉笔试写样例](assets/chalk-freehand-demo-2026-09-09.html)后，可以直接自由书写，通过黑板左下方的实物粉笔换色，并尝试板擦与导出。页面自带固定示例字体和授权，保存为本地 HTML 后也可独立打开，不访问真实账号或网站画板；页面内笔迹只保留在当前页面，刷新前可导出保存。

![由实际画笔程序生成的样张](assets/chalk-renderer-sample-2026-09-09.png)

这张样张由原型的实际画笔渲染程序生成，包含自由点列的白色波浪线、浅蓝曲线和淡黄三角形。没有调用图像生成模型来绘制这些笔迹，也没有把效果图上的笔画剪下来作为画笔素材。

## 原型的具体方法

输入点沿笔迹长度重新采样，使颗粒密度不取决于指针事件发生得快慢。边缘宽度的细小起伏根据笔迹 ID 生成，纸面颗粒位置固定；同一组点、同一 ID 和同一渲染版本重复绘制时，纹理规则保持一致。不同浏览器和设备可能有轻微抗锯齿差异，因此不承诺跨设备逐像素完全相同。

绘制先生成小范围的笔迹形状，再在其内部应用颗粒透明度，避免每次都重画整个场景背景。已完成笔迹缓存到图层，拖动时只更新当前笔迹，下一帧再合成；颗粒是静态的，不会每帧随机闪动。原型保持现有点列、颜色和宽度概念，正式接入时应记录渲染版本，以便以后调整笔触时兼容已有内容。

左下方粉笔本身承担固定颜色选择，选中后通过轻微位置或边缘提示表达状态。自定义颜色能力可继续按需出现，不需要在工具条里再常驻一套重复颜色圆点；使用板擦后，重新点击粉笔可以直接回到绘画。

## 与现有画板的衔接

当前 app/Whiteboard.tsx 在页面上绘制实色 SVG 路径，导出时又在白色 Canvas 上绘制实色路径。仅给网页路径添加视觉滤镜，会导致导出仍是普通实线，因此正式接入必须让可见笔迹和导出调用一致的笔触规则，同时将背景与文本样式纳入导出验证。

多人同步仍传递笔迹数据，不需要连续上传生成图片或为颗粒另开轮询。本轮没有接入实时房间，不能把同一组数据的重复绘制检查称为多人联机验收；旧画板、文本拖动及多画板选择也还要在正式接入时验证。

当前原型的板擦在本地图层上执行擦除，用来验证颗粒能被正确抹去。正式协作画板需要保留已有的擦除消息、记录和权限语义，并让整笔及局部擦除在重连后仍一致，不能直接用演示页的临时像素结果代替正式数据。

## 已完成检查与限制

独立检查验证了沿线重新采样、空点列、单点绘制及无效重复点的处理，并确认同一笔迹经过数据序列化后重复绘制结果一致。样张中存在实际透明度颗粒，局部擦除能清除目标位置；程序能够生成 PNG，试写页脚本也通过语法检查。

浏览器中已实际打开页面，核对了控件和字样，点击蓝色粉笔后用拖动新增了一笔，页面显示对应选色与笔迹计数。后续涉及板擦、撤销和字体切换的浏览器操作被自动审批审查拒绝，系统未给出具体原因，因此这些浏览器交互以及移动端触控、触控笔压力尚未标记为已验证。独立程序擦除检查与浏览器按钮操作检查分别记录，不互相替代。

本轮没有将原型接入网站。图像生成工具重试后返回额度用尽，新的整页状态图也尚未完成；原型和字体对比是可检查的技术成果，当前设计要求继续记录在[教室主题说明](classroom-flat-style-2026-09-09.md)与原需求表中。
