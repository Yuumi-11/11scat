# 设置菜单实施记录

日期：2026-09-08。按用户最新补充，顶部独立的“外观设置”入口改为齿轮图标的“设置”，消息铃声提醒与外观设置放在同一级子菜单。教室学院主题尚未实施，审批与滴答外部勾选同步也只登记为后续需求。

## 操作方式

点击顶部“设置”后，显示“消息铃声提醒”和“外观设置”两项。进入子菜单后可通过左上角返回按钮回到设置列表，关闭按钮关闭整个面板；按 Escape 时先返回设置列表，再按一次关闭，关闭后焦点回到顶部设置按钮。

消息铃声提醒子菜单承接原来的设备通知开关、授权提示及手机和手表说明。网页消息提示音的原有播放逻辑未变，本轮没有新增音量、静音或铃声选择功能；设备通知设置不再需要经过外观设置才能进入。

外观设置暂时保留原来的四种预设、自由选色和背景图片操作。此前未采纳的六种近白预设与配色参数已撤回，当前采用发布版本 `f7e7637` 的配色代码，新的学院主题等待后续设计。

## 扩展与保留范围

设置组件接收分类列表，每个分类包含名称、图标及内容，后续设置可增加同级子菜单。没有显示尚不存在的功能入口，面板使用原生模态对话框，支持键盘焦点限制和移动端滚动。

本次保留“传纸条”“同桌”“任务板”的改名、任务板图标和新公共任务角标逻辑，认领审批及其权限规则也保持现状。配色调研报告与效果图保留为历史材料，不代表已确认的学院主题方案。
