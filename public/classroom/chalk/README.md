# 粉笔图案与工具素材

2026-09-10 新增内置生图制作的[手绘粉笔素材](handdrawn/README.md)，当前装饰样例已使用这批独立透明图片。以下内容继续记录原 SVG 和工具的维护方式，工具文件保持原有调用。

这一组素材使用可编辑的矢量路径，配色沿用当前教室的米白、浅黄、粉红和淡蓝。四款装饰为爱心、星星、气球与猫咪，工具图案包括文本、清屏、保存以及两种全屏状态。

## 延续画风

- 装饰统一采用 `160 × 160` 画布，工具采用 `32 × 32`；大小版本共用源文件，只能等比缩放、平移或旋转。
- 线条保留轻微不规则形状，以重叠笔迹和固定种子的颗粒留白模拟粉笔，不增加光泽、立体高光或复杂阴影。
- 配色固定为米白 `#f5efdb`、浅黄 `#efd28a`、粉红 `#e6b1ba`、淡蓝 `#a4c5de`，大面积填充保持低透明度。工具使用 `#f6f1dc`。
- 后续增加图案时，在生成器的 `motifs` 中增加路径，复用现有线宽、颗粒和颜色；不要重新绘制已确认的图案。

在项目根目录运行 `node scripts/generate-classroom-chalk.mjs` 可重建这九个 SVG。相同路径和参数会输出相同文件；修改路径后需同时更新源文件与生成结果，并在大小样例中检查可辨识度。

本地对照页为 `/classroom-preview/chalk-art`，装饰图案的常规大小为 160 像素，小样为 52 像素。手机对照页对应缩至 140 与 44 像素，不改变比例。左上角与右下角可以在样例中独立组合。

当前只制作素材。每日随机更换、用户手动选择后的持久化、房间内同步，以及正式黑板上的图案位置均按用户要求暂不接入。
