11scat 音乐连接（Windows x64）

1. 打开桌面网易云音乐。
2. 运行 11scat-Music.exe，复制配对码。
3. 在 study.11scat.xyz 的音乐小窗 → 更多 → 连接桌面网易云中粘贴配对码。
4. 勾选允许请求收听，再发起或接受邀请。接受前只在本机采集，不向网站上传音乐。
5. 收听方在网站接受邀请后点击“开始收听”。收听方无需运行此程序。

窗口关闭即停止采集。程序不安装服务、不自动启动、不修改网易云、不采集麦克风、不保存录音。
采集仅限 cloudmusic 进程树。Windows 构建号必须达到 20348，建议 Windows 11 x64。
配对码仅当前运行期间有效，不要发给对方；双方各自使用自己的配对码。
本机端口 19743 只接受 study.11scat.xyz 和本地开发站点 127.0.0.1:3112，且必须提供配对码。
本程序尚无代码签名。请核对网站提供的 SHA-256；不要通过关闭系统安全软件来运行。
当前版本只分享声音，不提供歌曲名、封面或远程切歌。

源码：本项目 native/music-bridge/Bridge.cs。音频接口依据 Microsoft Windows process-loopback API 自行实现。
